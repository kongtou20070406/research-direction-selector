# DL 第一性原理：两条有条件的原理，四条可当场验证的推导链

这份文件说明另外三份文档为什么长成那样。它不重复证据，只给推导。
证据库：`neural-frontier-presets.md`（A-I，30 条）、`dl-diagnosis-first.md`（D1-D7）。

**阅读方式**：下面的原理都带条件。不加条件的版本更漂亮，但会被一条反例打穿，
而且会变成新的教条。每条都写了「它不覆盖什么」。

## L2-A：经验风险对解欠定，训练协议选择解

训练目标很少唯一确定一个解。梯度下降、正则化强度、数据顺序、批大小、warmup
共同从等价的解集合里挑出一个。**被挑中哪个，决定了泛化，而不是目标函数决定了
泛化。**

这条能推出四件事，每件都能当场验证：

| 推论 | 前提（必须成立，否则推论不成立） | 验证 |
|---|---|---|
| 数据顺序改变结果 | 两步更新不交换（存在非零交换子） | 同数据两种顺序，同一 seed，比较权重差异 |
| weight decay 选择不同的解 | 不同正则代价下，插值解不唯一 | 训练 loss 匹配的两组，比较测试集 |
| LR 不能跨规模迁移 | 规模变化移动了有效正则尺度 | 小模型调好的 LR 直接搬到大模型 |
| 同样的 loss，不同的模型 | 存在多个经验风险相同的点 | 匹配训练 loss 的协议 × 架构交叉 |

**它不覆盖**：目标函数确实唯一确定解的任务（强凸、无过参数化、凸损失）。
在那些任务上，协议选择解这件事退化成数值误差。

## L2-B：指标是对行为的有损投影

任何指标都是把「模型做了什么」压成一个数。压缩必然丢信息，而丢哪部分取决于
指标的构造，不取决于模型。**所以指标之间的分歧是常态，不是异常。**

| 推论 | 前提 | 验证 |
|---|---|---|
| 涌现可以是度量制造的 | 能力是连续的，计分是阈值化的 | 换连续指标重画，看峭壁是否消失 |
| 低 loss 不保证 OOD | 训练支持集外的函数行为未被约束 | 在支持集外采样，看 loss 与位置是否脱钩 |
| CoT trace 不忠实 | 输出通道与计算通道可分离 | 同一答案，扰动输入看 trace 是否跟着变 |
| 探针找到 ≠ 模型用得上 | 探针是离线线性读，不干预前向 | 做干预实验，看行为是否改变 |

**它不覆盖**：指标与行为一一对应的场景（单任务、单指标、任务本身就是指标的
任务，比如纯回归的 MSE）。那里投影几乎无损。

## L1：三条机制（在特定条件下成立，不是普适）

这三条比 L2 低一层：它们是「某种情况下会发生什么」，不是「必然如此」。

### M1. 两段时间尺度（有条件）

拟合快、压缩慢，标准训练只主动优化第一段。**条件**：存在可以被压缩掉的
冗余信息，且正则化足以驱动收缩。**推导**：grokking（A1）、double descent 的
第二次下降（A3b）、benign overfitting（A4）、早停有害（D4）。

**不覆盖**：单 epoch、数据远大于参数的训练里，第二段可能短到测不出来；也不能
把「两段」当成所有训练曲线的形状。

### M2. 表现由编码承载，不只由函数承载（有条件）

存在 loss 相同、编码效率不同的模型时，「学会 X」这句话不完整。**条件**：存在
可压缩的冗余表示。**推导**：SAE/探针失败（C2）、superposition 与对抗脆弱（C3）、
Attention sink（C1）、perplexity 盲点（E2）。

**不覆盖**：压缩不是唯一机制，它只是目前有测量的一种。别把「压缩」当成解释
一切的词，它没有参考类，也没有可比的单位。

### M3. 归纳偏置来自不受观测的默认值（有条件）

初始化、数据顺序、正则化强度、warmup、模型身份这些东西不在论文标题里，但在
起作用。**条件**：这些默认值在两组实验之间不同。**推导**：LR 不迁移（B2）、
warmup 是稳定装置（B4）、数据过滤非免费（D2）、dropout 失效（I1）。

**不覆盖**：这里的「优先级」没有定理支撑。说「weight decay 比架构重要」是一个
测量结果，不是一个排序定律；换个任务可以反过来。

## 一个观察姿态，不是定理

把上面的东西串起来，有一个好用的姿态：

> 没有「模型的能力」，只有「在某个条件下的可测表现」。

它的作用是让你**先问条件再问结论**（在第几段测的？用哪个指标？数据什么顺序？
模型哪个版本？）。它不可证伪，所以它不是 L2 的一条原理，而是一条提问的顺序。
写成定理会变成教条；当作启发式，它会持续有用。

它也是 RDS 三条契约的直觉来源：记录坐标（单一账本）、投影不是本体
（任务真值≠科学支持）、坐标缺失时拒绝下结论（fail-closed）。

---

## 这改变了什么行为

| 默认做法 | 有这两条原理之后 |
|---|---|
| 训练到收敛，看指标 | 先问「这个指标在第几段测的」 |
| 比两个模型的 loss | 比两个模型在**匹配训练 loss** 下的表现 |
| 记录超参 | 记录**默认值**：初始化、数据顺序、warmup、模型身份 |
| 一个度量定结论 | 每个结论声明它的连续对应物 |
| 「它学会了 X」 | 「在条件 C 下，用编码 E，测到 X」 |
| 预算用完判失败 | 三种终态：无信号 / 有证据反驳 / 被条件阻塞 |
| 只控参数量做架构对比 | **匹配训练 loss** 的协议 × 架构交叉 |

最后一行是操作上最容易被忽略的一条：比较两个架构时，如果训练 loss 不匹配，
你比的是「优化难度」，不是「归纳偏置」。

---

## 为什么这解释了 RDS 的设计

L2 说：解不唯一，指标是投影。那么一个科研系统的价值不在于「提高能力」，而在于
**把选择的坐标记录清楚，让下一个观测者能复现同一个解**。

三条契约正好对上：单一账本记坐标；任务真值≠科学支持（投影不是本体）；
fail-closed（坐标缺失时拒绝下结论）。

所以 RDS 的自我定位可以说成：**它是投影仪的口径记录仪，不是望远镜。**

这也解释了为什么它在 NewtonBench 上输了 0.674 却仍有意义——那个对比测的是
「谁更会找定律」，而 RDS 的主张从来不是这个。同时也解释了为什么那个结果必须
公布：**如果口径记录仪自己开始声称发现能力，它就变成了它要防的东西。**

## UNKNOWN

- M1 在 LLM 规模上是否成立，没有测过。玩具任务上稳，外推是假设。
- M2 的编码效率目前只有小型受控实验的量化（25× vs 5×），前沿模型上无对应测量。
- M3 的「优先级」是测量结果，不是排序定律；不同任务可以反转。
- 两条 L2 都带条件，条件不成立时推论不成立。把它们当无条件定理使用，会得到
  一个和 2018 教科书同样教条的新版教科书。
