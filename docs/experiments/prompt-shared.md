# 任务：图像去雾

两臂共用这一份。课题、数据、约束、评分口径、选模规则、seed 清单全部相同。
两臂的唯一差异写在末尾「记账方式」，并且不改任何上面的规则。

## 工作目录

运行前会告诉你实际目录。所有产物只写在该目录，不要写到别处。

## 数据

根目录 `D:/Myfile/data/ohaze`

| 划分 | 内容 |
|---|---|
| 训练集 | `train/GT/NN_outdoor_GT.jpg` 与 `train/hazy/NN_outdoor_hazy.jpg`，编号 **01–35**，成对，35 对 |
| 开发集 | 同目录，编号 **36–40**，成对，5 对 |
| 测试输入 | 工作目录下 `test_hazy/` 的 5 张带雾图（41–45），**没有对应的清晰图** |

每对第一张是清晰图，第二张是同一场景的带雾图。雾是实拍的，不是合成的。

## 约束

- 可学习参数总数 ≤ 50,000。超出即无效。
- 前向次数、迭代步数：不限。
- 禁止预训练权重、禁止外部数据。
- 单卡，3 小时墙钟。

## 评分口径（冻结，两臂相同，不许改）

- PSNR：sRGB，先 clip 到 [0,1]，再 round 到 uint8，裁边 4 像素，逐图算。
- SSIM：`skimage.metrics.structural_similarity`，默认参数，`data_range=255`，`channel_axis=-1`。
- 两个数都报逐图分数，再报平均。
- 选 checkpoint：开发集五张的**平均 PSNR**最高的那一个。
- seed 清单：`[0, 1, 2]`，三个都要跑，报三个的 dev 分数和方差，不许只交最好的那个。

## 禁止的三件事

- 不要用开发集的清晰图去更新模型参数或拟合逐图规则。开发集只用来选 checkpoint。
- 不要用 `test_hazy/` 的图去更新权重、选超参、或计算跨图统计。它们只供最终冻结的程序做一次推理。
- 输入、处理、输出都保持原生分辨率。禁止缩小再放大。

## 交付

1. `out/41.jpg` … `out/45.jpg`：五张去雾结果，尺寸与输入完全一致。
2. `out_dev/36.jpg` … `out_dev/40.jpg`：开发集五张的去雾结果，同样尺寸。
3. `report.md`：一句话说清结构、参数量、实际耗时。
4. `dev_scores.json`：你自己算的 dev 逐图 PSNR 与 SSIM。评测方会用同一口径重算，两者不一致超过 0.05 dB 则该臂无效。

## 注意

- 测试集的清晰图你拿不到，不要去网上找，也不要假设能拿到。
- 口径有问题写进 `report.md`，不要自己换一套。
