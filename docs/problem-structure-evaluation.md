## Single real-Agent connectivity probe

`examples/explanation-loop/run.py` provides a separate, explicitly invoked
real-model probe. It executes a failing linear candidate, returns verified
original residuals, and only then launches one native Codex call through the
existing project runner and budget. The model generates two bounded arithmetic
ASTs and commits different predictions at an unobserved diagnostic point. A
frozen independent oracle produces the measurement; structure admission,
selection and feedback consume the original evidence. No second hypothesis is
prewritten. The initial failure and arithmetic language are declared public
engineering fixtures; this is not a discovery benchmark.

```powershell
python -B examples/explanation-loop/run.py --workspace <new-sibling-directory> --codex <exact-native-codex-executable>
```

The explicit harness permits one `gpt-6.1-sol`, high-effort, default-tier call,
180 provider seconds, 190 owned worker seconds, in a 600 wall-second project.
Provider executable/configuration, scripts, data and evaluator are frozen.
Dispatch intent, original prompt, JSONL trace, stderr, schema, reply, receipts,
proposal, feedback and final route are retained. Uncertain delivery is not
retried. The prompt gives failure originals and public observations; trace tool
use invalidates this prompt-only visibility check. Read-only tools are not a
sealed secrecy boundary. Provider-reported tokens remain separate from unknown
currency/CPU/GPU usage and outer orchestration time. Actual model version is
only claimed if exposed by the provider, not inferred from a requested name.

A completed trajectory establishes connectivity on one finite task. It cannot
establish stable capability gain. The matched trial protocol below remains
NOT_RUN and scientific benefit remains UNMEASURED.

records one actual model call after an original linear failure. It generated
