# RDS 5.9.0-rc.1 preview

This prerelease is a trial of the current `main` line after 5.8.0. It does not
include the open [PR #189](https://github.com/kongtou20070406/research-direction-selector/pull/189)
for optimizing reusable proof plans. Use the release page's source and host
packages to get the exact published revision.

## Preview scope

- Continue bounded project work from the same ledger after a pass yields, while
  preserving the original goal, contract, reservations, costs and evidence.
- Request model repairs with bounded, hash-checked task-input and original-output
  excerpts. The shared excerpt allowance is limited to 64 KiB; this is not the
  full task, dataset or execution environment.
- Offer an optional evidence-bound working set assembled from owned project
  records, goals, budgets and missing evidence, reducing irrelevant context
  without treating retrieved material as verified fact.
- Retain alternative problem structures, their dependencies and rival
  predictions, then use verified feedback to activate, reject or roll back a
  candidate and replan within the declared budget.
- Route supported exact-math requests through bounded tools and count a result
  only after the registered independent checker accepts its certificate.
- Preserve oversized or incomplete outputs as unresolved evidence rather than
  treating a successful process exit as a correct research result.

These are engineering capabilities with declared scopes. The structural
exploration work has not established that a model independently discovers a
better research strategy. No end-to-end scientific capability gain is claimed;
the matched-model evaluation remains in [Issue #166](https://github.com/kongtou20070406/research-direction-selector/issues/166).

## Trial status

This is a release candidate, not a stable compatibility promise. The release
page identifies the exact tagged commit and its CI run. CI establishes only the
software checks that ran; research benefit, unsupported domains and unmeasured
resource costs remain unknown.
