# RDS 6.1.0

状态：没有单独发布，也没有标签。随 [6.2.0](6.2.0.md) 一起发布。

## 这次多了什么

普通科研有一条插件路线。声明 `goal.kind` 为 `OPEN` 时，内核只给一张卡，并记下一条事实。工具和 MCP 仍由宿主调用。

- 卡不超过 4096 字节。里面是目标、判据哈希、最多 5 条试验、最多 1 条冲突、一个问题。
- `next` 只能是 `ANSWER`、`RECORD`、`REUSE`、`STOP`。技能要求先回答问题，再调用外层工具。
- `compass record` 只追加一条试验或冲突。它不运行命令，也不调用模型。
- 相同命令路由再次登记，返回 `REUSE`。同一路由失败两次，卡变成 `STOP`。
- 旧的 `IDENTIFY_LAW` 和 `IMPROVE` 声明不变。默认技能不再走进语法合成、EIG、盆地逃逸或 RSI。

## 不证明什么

- 不证明科学发现。`scientific_support` 仍是 `UNKNOWN`。
- 不证明比不使用这张卡的模型更准，也不证明更省 token。
- 没有容差或停止规则时不比较、不补默认值，卡直接 `STOP`。
- 记录来自调用方报告。`INPUT_REPORTED` 不是支持，也不是反驳。
- GPT-6 Luna 的两臂评估还没有真实用量。在用量回报之前，结论是 `UNKNOWN`，不是 0。
