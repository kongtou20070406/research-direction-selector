# RDS 自我改进飞轮：红队审查

## 判断

「RDS 用于改进 RDS 自身」可以作为待检验的工程假设，当前材料不足以支持「RSI 指数 `r > 1`」。现有证据是 Compass 的合成机制探针与单次 NewtonBench Pareto 扫描，不是 RDS 改进 RDS 后的跨轮科研生产率测量。`r` 还没有操作性定义：若它表示每轮改进幅度的乘数，必须明确分子、分母、时间窗、成本单位、独立样本和不确定区间；只报告某个能力指标变好，不等于迭代增益大于一。

## 1. 选择效应：RDS 挑实验会偏向什么

会。若 RDS 决定「最可能区分改动」的任务、探针点或候选改动，再用这些结果估计自身收益，选择策略与评估样本就不独立。它会倾向于挑出对自己当前假设空间、候选生成器和验证流程最敏感的局部问题；未被选中的能力退化、分布外失败和成本都不会进入平均数。

具体机制：

- **可解性富集**：若实验按预期信息增益、可区分候选数或容易获得的回执排序，有限预算会集中到 RDS 已有算子、任务表示和工具能处理的区域。表达能力缺口大的问题可能被预测为低收益而不买，最后的成功率条件化在「RDS 愿意测」的任务上。
- **胜者偏差**：从很多任务/改动组合里挑观察到差异最大者，再把该差异当作泛化增益，会把噪声和偶然有利的任务一起选进分子。反复自适应挑选还会让后续轮次沿着早期噪声方向继续优化。
- **基准贴合**：如果系统能看到任务集、真值构造规律、预算或评价函数，它可以优先提出能改善这些具体分数的改动。即使总分上升，也可能只是对生成器或基准的适配。
- **只计被识别的成功**：`pareto.py` 的 RDS 行同时保留 `claim_exact`、`best_effort_exact` 与 `exact_match`。例如 `sparse-mid` 在预算 8 时 `best_effort_exact=31`、但 `claim_exact=0`、`exact_match=0`，因为候选 claim 未建立；这三列回答不同问题。若飞轮挑对自身有利的列、预算或任务子集汇总，方向可以被人为翻转。

现有 `pareto.py` 固定了三种世界：两个稀疏异常和一个 regime 切换，预算为 6、8、12、16、24、32。RDS 和 baseline 都看到同一批世界，但这是针对已知合成形状的机制比较，不是从未见任务分布抽取的独立评估。结果里 baseline 对 `sparse-mid` 在多个预算下得到 31/32，而 RDS 有些预算未建立 claim；RDS 在其他任务/预算能达到 31 或 32。不能只挑有利单元格概括飞轮收益。

## 2. 口径漂移：怎样把变化伪装成加速

两轮若改指标、容差或任务集，哪怕底层能力不变，也能制造「每轮更快」：

- **指标变宽**：从精确真值匹配改成近似误差低于容差，会把原先失败改记为成功；放宽 replay 容差也会增加可接受 claim。
- **分母变轻**：删掉稀疏异常、边界点或耗时任务，或把更容易的新任务加进任务集，平均成功数、正确率和每正确解时间都会变好。
- **状态口径改变**：把 `best_effort_exact`、与已测点一致、`GOAL_IDENTIFIED`、完整域精确正确混成同一个「正确解」，就能把部分拟合或未经独立验证的候选算作产出。`compass-yield.md` 明确说其 claim 是 `INPUT_REPORTED` 且 `scientific_support: UNKNOWN`；不得将流程状态改写成科学支持。
- **预算口径缩小**：只计实验次数或 agent 报告 token，不计候选搜索、失败尝试、工具运行和人工复核，会让每正确解成本看似下降。

冻结口径的三道闸门：

1. **预注册评估集与切分**：在改动开始前固定任务生成规则、隐藏 holdout、版本/哈希、随机种子与纳入排除规则；RDS 可在训练/开发集选实验，最终分数只能由未见 holdout 计算。每轮保留失败与未决样本，不得事后删题。
2. **冻结指标和裁决器**：锁定真值比较方式、容差、成功定义、独立复核程序及其版本哈希。分别报告独立复核正确率、假认证率、未决率、覆盖率与按预注册规则计算的汇总；`INPUT_REPORTED`、部分拟合和与已测回执一致不得计为独立确认正确。
3. **冻结同资源对照与完整账本**：同一模型、同一初始能力/上下文、相同任务、总预算、运行环境和截止规则，对比「RDS 改进流程」与基线；每轮按同一成本账本计所有消耗，并报告配对差、跨任务不确定区间。修改任务、容差、预算或成本边界时，作为新实验版本重新开始，不与旧轮直接拼接。

## 3. 循环定义：谁复核 RDS 的改动

复核者应与提出改动和选择实验的链路独立：冻结的外部 verifier、未参与开发的审稿者/领域专家，或两者组合。复核者应拿到原始测量、回执、代码与环境身份，在隐藏任务上重放，依据预先登记的科学标准判定。若 RDS 自己既挑改动、挑实验、解释结果又给自己打分，测到的是内部一致性或可审计执行，不是独立科研支持。

若复核仍由 RDS 完成，缺少的是**误差相关性隔离**：同一表示、假设空间、工具、候选排序、停止规则和缺陷可同时影响被测方案与裁决器。即便重复运行、换 prompt 或换一个 RDS 实例，也不能自动形成独立性。至少要有被冻结的外部判据、对开发者隐藏的 holdout 和可复现的原始输出；对高影响科研结论还需领域专家审阅关键假设与实验设计。Compass 文档的原则也明确：候选工具的 `verified=true` 不是科学确认，支持状态必须由原始测量经冻结的独立 verifier 重放决定。

## 4. 成本漏算：哪些账会让 r 虚高

`compass-yield.md` 的成本可见性表述为 experiments、jumps 和 agent reported token spend；这不等于完整成本账。未纳入或未被独立计量的项目至少包括：

- 提示词、上下文、重试、规划与分析的全部输入/输出 token；系统若只上报自己的 token 数，账目不是外部计量。
- 所有实验买点、确认点、holdout 点、失败/中断尝试及重复运行的调用次数与费用；实验数下降不表示一次实验更便宜。
- 搜索和验证的墙钟时间，包括等待、编译、数据处理、序列化和人工介入；只计模型活跃时间会漏掉端到端延迟。
- PySR/Julia 的 CPU 核时、内存、启动/预编译时间和并行资源；`compass-yield.md` 给出的 PySR frontier 搜索时间为 3.0 s，且说明搜索时间单独记录。若飞轮总账没有把这类搜索成本按同一规则纳入，就会把昂贵的候选生成算成免费增益。
- 开发和调试本轮改动、维护基准、失败试验、独立复核以及复核者时间；若主张的是科研收益，还要计入从候选到可复核正确结果的全部边际成本。

当每轮的「收益」只计正确数或实验数，而成本漏掉这些项目，`r = 本轮产出 / 上轮产出` 或任何按成本归一的增长率都可能虚高。至少同时报告每个独立复核正确解的总 token、实验/工具调用、CPU 核时和墙钟成本；不能合并成一个未说明权重的数字。

## 5. 最小反例：表面 r>1，实际只是选择效应

构造 100 个预先固定的隐藏任务：其中 10 个属于 RDS 擅长的稀疏线性任务，90 个属于当前表示不擅长的分段/异常任务。某轮改动没有改变任何任务上的真实性能。RDS 自适应地只选「最可能区分这次改动」的任务，选中 10 个擅长任务并全部通过；旧轮报告基于全量任务，正确率 0.10，新轮只报告被选中的 10 个，正确率 1.00。若把这两个条件不同的分数相除，会得到表面 `r = 10`，但全量隐藏集仍是 10/100，真实改进为零。若评估过程还优先报告最优预算点或最优指标，偏差会更大。

杀死这个反例的最小设计：实验选择只能作用于开发集，固定隐藏集上的所有任务必须无条件计分；每个任务都按冻结定义计为独立复核正确、错误或未决。将失败和未决留在分母，并由未参与选择的 verifier 判定。

## 6. 不能宣称什么

在独立、冻结、同预算评估完成前，不能宣称：

- 「RSI 指数 `r > 1`」「递归自我改进已启动」或「收益会逐轮复利」。目前 `r` 没有冻结定义，也没有多轮独立估计和不确定区间。
- RDS 的改动提高了普遍科研能力、可迁移到未见领域，或优于同模型基线。当前 Compass yield 是确定性 `N=1` 的小型合成机制探针；文档明确没有外部 benchmark，也没有试验方差。
- `GOAL_IDENTIFIED`、`CONSISTENT_WITH_ALL_RECEIPTED_MEASUREMENTS`、`verified=true` 或某个精确匹配列等同于科学结论正确。它们不能替代原始测量上的冻结独立复核。
- Pareto 单次扫描证明了总体成本效率、长期加速或统计显著性。三个合成世界、若干预算点和单次结果不构成跨分布推断；不同列也不可混为同一成功定义。
- token/实验数下降就意味着总成本下降。若墙钟、CPU、PySR/Julia、失败尝试和独立复核未完整入账，成本结论不成立。
- RDS 的自我评价构成独立验证。重复调用自身、改写 prompt 或挑选有利任务不能消除共同失效模式。

一句话结论：先把 `r` 定义为冻结隐藏集上、经独立复核的正确科研结果相对同预算基线的增益，并完整计入成本；在此之前，飞轮是待证假设，不是已观察到的 `r > 1`。
